# Glossary

This document lists terms and definitions used in this project.

> [!NOTE]
> When we introduce new term we usually append it to the Glossary.md and 
> reference its glossary position from everywhere we use it.

| Term  | Definition |
| ------------- | ------------- |
| technical project  | A distinct build/deployment unit. May contain one or many parts(or entire body) of functional or technical modules.  |
| module  | A self-contained unit of code, either functional or technical, which serves a specific purpose in the system. May span across one or many technical projects.  |
| functional module  | A module whose responsibility contributes to producing, transforming, or interpreting information that provides value to the system’s primary audience, including through intermediate processing stages.  |
| technical module  | A module that supports the system’s operation and infrastructure but does not directly contribute to producing or transforming information that provides value to the system’s primary audience.  |
| Architectural documentation category  | Documents and diagrams that describe the logical organization, responsibilities, and interactions of functional modules within the system. Helps developers understand what the system does, how modules relate, and how to reason about system structure.  |
| Technical documentation category  | Documents describing the technical composition, implementation details, and structural organization of the system. Supports developers in locating, building, and understanding technical modules and components.  |
| Operational documentation category  | Documents that explain how to correctly operate, maintain, and utilize the system across its lifecycle. Ensures consistent use of the system by developers, administrators, or end users.  |
| Development operational documentation subcategory  | Guidelines, practices, and tips for developing the system correctly, including coding conventions, checklists, and consistency rules.  |
| Build operational documentation subcategory  | Instructions and conventions for compiling, building, and packaging system components.  |
| Deploy and utilization operational documentation subcategory  | Guidelines for deploying the system and using it in production or test environments. Supports administrators and users in installing, configuring, and using the system safely and effectively.  |
