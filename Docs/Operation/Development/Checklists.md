# Common checklist

Requirements to check before applying changes to project.

1. Make sure you follow [conventions](Conventions.md).
2. Make sure requirements described at [EntityConsistencyList.md](../EntityConsistencyList.md) are met.
3. Make sure you use consistent definitions with [Glossary.md](../Glossary.md).
